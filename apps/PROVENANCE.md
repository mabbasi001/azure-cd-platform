# Application Provenance

The applications under `apps/` are existing RealWorld implementations, vendored into this
repository as the deployment target for the CD platform. They were imported pristine and then
containerized; the git history records exactly what was changed.

| App | Upstream | License |
|-----|----------|---------|
| `frontend` | https://github.com/gothinkster/react-redux-realworld-example-app | MIT (`frontend/LICENSE.md`) |
| `backend` | https://github.com/nsidnev/fastapi-realworld-example-app | MIT (`backend/LICENSE`) |

## Local changes

- **frontend** — API base URL is resolved at runtime from `window._env_.API_URL`
  (`public/config.js`, generated by the nginx container at start-up) instead of the hardcoded
  upstream constant. Added a multi-stage `Dockerfile` (Node 16 build, nginx runtime) and nginx
  config.
- **backend** — replaced the upstream `Dockerfile` with a multi-stage build (compile
  dependencies in a builder, run from a slim image). Removed the app-local `docker-compose.yml`
  in favour of the top-level `apps/docker-compose.yml`.
